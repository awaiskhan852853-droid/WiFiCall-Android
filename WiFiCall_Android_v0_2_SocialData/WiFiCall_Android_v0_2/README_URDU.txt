WiFi Call Android Starter — Version 0.2
======================================

یہ پروجیکٹ ابھی UI prototype ہے۔ حقیقی آڈیو کالنگ، سوشل ڈیٹا zero-rating،
عام موبائل نمبر پر کال، والٹ یا ادائیگی ابھی فعال نہیں۔

نیا اضافہ:
SOCIAL_DATA_BUSINESS_PLAN_URDU.txt میں چار نیٹ ورکس کے لیے سوشل ڈیٹا پارٹنرشپ،
تکنیکی طریقہ، کاروباری مراحل اور قانونی احتیاط درج ہے۔

Build:
1. ZIP extract کریں۔
2. Android Studio میں فولڈر Open کریں۔
3. Gradle Sync مکمل ہونے دیں۔
4. Android SDK Platform 35 اور JDK 17 درکار ہیں۔
5. فون USB debugging کے ذریعے جوڑیں اور Run دبائیں۔

App ID: com.wificall.app
Version: 0.2.0 plan update (UI prototype remains 0.1.0)
